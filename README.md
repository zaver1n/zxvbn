# Книжный дом

Веб-приложение для управления библиотекой: каталог и поиск книг, читатели,
редактирование и удаление записей, выдача и возврат со сроком сдачи,
индикация просрочки, статистика и расчёт штрафа (100 ₸ за день).
Сайт сделан на HTML/CSS/JavaScript, без базы данных. Книги и читатели
сохраняются в локальном хранилище браузера (`localStorage`).

## Запуск

Из папки `LibrarySite` запустите статический веб-сервер:

```powershell
dotnet run
```

Откройте локальный адрес, указанный в выводе команды. Сервер только раздаёт
файлы сайта — он не подключается к базе и не хранит данные. При первом запуске
сайт добавляет демонстрационную книгу «Чистый код». Для каждой выдачи можно
указать срок возврата; по умолчанию устанавливается 14 дней. Дата и количество
дней просрочки отображаются в каталоге и учитываются при возврате. Читателя
нельзя удалить, пока у него есть выданные книги.

Данные доступны только в том браузере и на том устройстве, где их добавили.
Очистка данных сайта в браузере удалит сохранённую библиотеку.
